# Быстрый старт

## Запуск установленного приложения

1. Установите APK на Android-устройство.
2. Запустите FinanceTracker.
3. Выберите счёт «Наличные» или «Карта».
4. Добавьте доход или расход.
5. Откройте историю, чтобы проверить сохранённую операцию.

После первого запуска приложение автоматически создаёт два счёта: «Наличные» и «Карта».
