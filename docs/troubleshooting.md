# Устранение неисправностей

## Приложение не собирается

Проверьте подключение к интернету, синхронизацию Gradle и наличие Android SDK API 36.

## Не отображается баланс

Перезапустите приложение и проверьте, что операция была сохранена с непустой суммой.

## Не устанавливается APK

Убедитесь, что версия Android соответствует требованиям API 29 или выше, а установка приложений из выбранного источника разрешена.

## Ошибка после обновления

Зафиксируйте описание ошибки и вернитесь к предыдущему Git-тегу или APK рабочей версии. После этого проверьте сохранность локальных данных.
