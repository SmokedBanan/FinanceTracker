# Руководство пользователя

## Добавление дохода или расхода

1. На главном экране нажмите **Доход** или **Расход**.
2. Введите сумму.
3. Добавьте описание операции.
4. Нажмите **ОК**.

Баланс и диаграмма обновятся автоматически.

## Управление счетами

1. Нажмите карточку счетов.
2. Выберите существующий счёт или пункт **Добавить новый счёт**.
3. Для переключения активного счёта выберите его в списке.

## Просмотр истории

Нажмите карточку **История** на главном экране. Откроется список сохранённых операций.

## Пример сценария

```text
Создать счёт «Карта» → добавить доход 50000 → добавить расход 1200 → открыть историю
```
