# Справочная информация

## Основные компоненты

| Компонент | Назначение |
|---|---|
| `MainActivity` | Главный экран и добавление операций |
| `HistoryActivity` | Просмотр истории операций |
| `Transaction` | Модель операции дохода или расхода |
| `Account` | Модель счёта пользователя |
| `AppDatabase` | Локальная база данных Room |
| `TransactionDao` | Запросы к базе данных |

## Версионирование

Версии рекомендуется оформлять по схеме SemVer:

- `1.0.0` — первая рабочая версия;
- `1.1.0` — добавление новой функции;
- `1.1.1` — исправление ошибки.

Исходный код хранится в [GitHub-репозитории](https://github.com/SmokedBanan/FinanceTracker).
