## Цель работы

Создать связанную техническую документацию для приложения FinanceTracker с использованием Markdown, внутренней навигации, таблиц, ссылок, блоков кода и изображения-схемы.

## Объект документирования

FinanceTracker — мобильное Android-приложение для учёта личных финансов. Приложение позволяет добавлять доходы и расходы, управлять счетами, просматривать историю операций и отображать баланс с помощью диаграммы.

## Выполненные работы

1. Исходный проект FinanceTracker размещён в GitHub-репозитории.
2. Создана главная страница документации `docs/index.md`.
3. Добавлены разделы быстрого старта, установки, руководства пользователя, справочной информации и устранения неисправностей.
4. Организована навигация между Markdown-файлами с помощью внутренних ссылок.
5. Добавлена таблица системных требований и компонентов приложения.
6. Добавлены примеры команд сборки и пользовательского сценария.
7. Создана схема взаимодействия главного экрана, операций и локального хранилища.
8. Обновлён файл `README.md` со ссылками на разделы документации.

- заголовки и абзацы;
